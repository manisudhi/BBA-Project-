# Savitur Global Advisians LLP

The company website for Savitur Global Advisians LLP — a consulting and offshore services firm
delivering risk advisory, internal audit and end-to-end offshore accounting to clients across
India, the United Kingdom and South Africa.

Five pages, built with React and Vite, themed on the company logo's navy and gold.

| Page | What's on it |
| --- | --- |
| Home | Introduction, the six services, impact figures, approach and industries at a glance |
| About | The firm's story, founder spotlight on CA Neha Chawla, what sets the practice apart |
| Services | Each of the six practices in detail, the five-stage engagement method, FAQs |
| Industries | The nine sectors served, what we look for in each, markets and reporting frameworks |
| Contact | Contact details, an enquiry form, registered office and FAQs |

## Running it

You'll need [Node.js](https://nodejs.org) 18 or newer.

```bash
npm install     # first time only
npm run dev
```

Then open **http://localhost:5173**. The page reloads as you edit. `Ctrl+C` stops the server.

## Building for deployment

```bash
npm run build     # creates dist/
npm run preview   # check the built site at http://localhost:4173
```

`dist/` is a plain static folder. Upload it anywhere — Netlify, Vercel, Cloudflare Pages,
GitHub Pages, or ordinary cPanel hosting. For Netlify and Vercel, set the build command to
`npm run build` and the publish directory to `dist`.
